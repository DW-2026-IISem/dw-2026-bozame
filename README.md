Hola, soy Sharon y este es mi repositorio para la clase de desarrollo web.

Mi proyecto principal se llama **Entrega Nexo** (`pry-sbarboza/app-entreganexo/`). Es un sistema diseñado de forma sencilla para gestionar operaciones, ventas, productos y los permisos de acceso de diferentes usuarios.

Para explorar distintas formas de programación, el código del proyecto está dividido en tres carpetas diferentes:

* **Backend-manual (Node.js):** La versión básica construida de forma tradicional, paso a paso.
* **Backend IA:** La misma versión básica, pero desarrollada completamente con la ayuda de Inteligencia Artificial.
* **Backend-full (NestJS):** La versión más avanzada, estructurada y profesional del proyecto.
